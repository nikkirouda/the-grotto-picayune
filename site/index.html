Owner's key: gathering and sync

The paper gathers fresh stories only when a device holding the owner's key opens it or taps ↻. Paste a GitHub fine-grained token for this site's repository with Actions: read & write (for gathering) and Contents: read & write (to share votes and preferences between your devices). It never leaves this device except to talk to GitHub. Readers without the key see the latest edition and can pull a newer one with ↻.
